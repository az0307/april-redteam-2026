## 2.2 Methodology

Testing followed industry-standard frameworks:

```
RECONNAISSANCE
  └── Passive OSINT (AutoGPT), subdomain enum, tech fingerprinting

THREAT MODELING
  └── STRIDE analysis (STRIDE-GPT) — pre-engagement

ENUMERATION
  └── Port scanning (nmap), directory brute-force (ffuf/gobuster)
  └── Service version fingerprinting, API discovery

VULNERABILITY ANALYSIS
  └── Automated: nuclei (4000+ templates), VulnGPT CVE analysis
  └── Manual: OWASP Top 10, authentication testing, business logic

EXPLOITATION
  └── Confirmed vulnerabilities with working PoC
  └── No destructive actions without explicit approval

REPORTING
  └── CVSS v3.1 scoring, business impact assessment
  └── Threat model correlation (STRIDE-GPT post-engagement)
```
